Ejercicio 12: Raíces de una Ecuación Cuadrática

Descripción del Capítulo / Enunciado: Determina las raíces reales de una ecuación cuadrática de la forma ax² + bx + c = 0 calculando el discriminante D = b² - 4ac. Muestra mensajes específicos según si D > 0, D = 0 o D < 0.

Algoritmo: 1. Leer los coeficientes a, b y c. 2. Calcular el discriminante D = b² - 4ac. 3. Evaluar condiciones: si D > 0 calcular dos raíces reales; si D = 0 calcular una raíz única; si D < 0 indicar que no hay raíces reales.

Salida de datos: Ingrese los coeficientes y presione calcular.

Ejercicio 13: Estimación del valor de Pi por Series

Descripción del Capítulo / Enunciado: Estimar el valor de pi mediante la serie π = √(6 * Σ (1 / n²)) utilizando un bucle con un número determinado de términos N, comparando el resultado con el valor real de pi.

Algoritmo: 1. Leer el número de términos N. 2. Inicializar la suma en 0. 3. Mediante un bucle de n=1 hasta N, sumar 1 / (n * n). 4. Multiplicar la suma total por 6, extraer su raíz cuadrada y comparar con el valor real de pi.

Salida de datos: Ingrese N y presione calcular.

Ejercicio 3 (Libro): El Reparto de los 35 Camellos (Capítulo III)

Descripción del Capítulo: Beremiz Samir resuelve un conflicto entre tres hermanos que no lograban dividirse una herencia de 35 camellos según los deseos de su padre (1/2, 1/3 y 1/9). Beremiz añade su propio camello para realizar la división exacta.

Algoritmo: 1. Leer el total de camellos. 2. Sumar 1 camello auxiliar. 3. Calcular las porciones correspondientes dividiendo el nuevo total entre 2, 3 y 9. 4. Obtener el camello sobrante para Beremiz.

Salida de datos: Ingrese los datos y presione calcular.

Ejercicio 6 (Libro): El Pago de los Panes Compartidos (Capítulo VI)

Descripción del Capítulo: Dos viajeros comparten sus alimentos (5 panes y 3 panes) con un forastero. Al dejar 8 monedas de oro como pago, Beremiz demuestra que el dinero debe dividirse en proporción exacta al pan cedido.

Algoritmo: 1. Leer panes aportados y monedas de oro. 2. Calcular el consumo por persona (Total panes / 3). 3. Restar el consumo personal de los panes aportados para obtener la contribución neta. 4. Distribuir las monedas proporcionalmente.

Salida de datos: Ingrese los datos y presione calcular.
